## 2024-06-28 - Add missing alt text to image for accessibility
**Learning:** Some standalone HTML pages meant for testing or examples (like `test_tipc/web/index.html`) can omit basic accessibility attributes (`alt` on `<img>`). These pages are often used by other developers as reference or templates.
**Action:** Always ensure that images, especially in entry or example HTML files, include descriptive `alt` text to improve overall accessibility.
