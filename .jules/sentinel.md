## 2024-05-18 - Insecure YAML Deserialization in Config Parsing
**Vulnerability:** Widespread use of `yaml.load(..., Loader=yaml.Loader)` across configuration parsing utilities (`test_tipc/supplementary/config.py`, `configs/rec/multi_language/generate_multi_language_configs.py`, `benchmark/PaddleOCR_DBNet/utils/util.py`, `tools/program.py`).
**Learning:** PyYAML's `yaml.Loader` is insecure because it allows instantiation of arbitrary Python objects, leading to potential Remote Code Execution (RCE) if an attacker can supply a maliciously crafted YAML configuration file. The codebase relies heavily on YAML for configuration.
**Prevention:** Always use `yaml.load(..., Loader=yaml.SafeLoader)` or `yaml.safe_load(...)` for parsing YAML, especially when the source of the YAML file is untrusted or external.
