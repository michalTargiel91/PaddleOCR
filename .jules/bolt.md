## 2024-03-24 - Precomputing Shapely polygons in NMS
**Learning:** In PaddleOCR's `poly_nms`, calculating intersection over union using `boundary_iou` inside the nested loops is extremely slow because it rebuilds `shapely.geometry.Polygon` objects and uses buffered intersections via `poly_intersection` for every pair. Pre-computing unbuffered Shapely Polygons (and their areas) once per box and using `.intersection()` directly in the inner loop provides a massive ~8.5x speedup for 1000 polygons, dropping time from ~6.5s to ~0.75s. Pre-buffering polygons in Shapely can drastically reduce intersection performance.
**Action:** When implementing NMS over polygons, instantiate geometry objects once upfront and precompute areas to cache them. Perform unbuffered native `.intersection()` operations directly in inner loops, with a try/except fallback to standard operations for irregular geometries that cause topological errors.
