## 2024-08-28 - Optimizing Non-Maximum Suppression (NMS) for Polygons
**Learning:** In highly recursive inner loops calculating Intersection over Union (IoU) for irregular Shapely polygons (`poly_nms`), relying on helper functions that repeatedly instantiate `shapely.geometry.Polygon` objects inside the loop creates a severe performance bottleneck. Furthermore, `poly.buffer(0.0001)` creates additional polygon complexity that further degrades performance and should be avoided in caching loops.
**Action:** When performing heavily looped intersection calculations in Shapely, strictly pre-compute valid Polygon objects and their static areas in an initial linear pass, falling back to a dummy state (like `None`) for topological failures. Calculate union operations mathematically using the cached base areas to bypass repeated expensive buffered intersection calls.
