## 2024-05-24 - Pre-compute Shapely geometries to avoid O(N^2) instantiation
**Learning:** In operations like `poly_nms`, creating Shapely `Polygon` objects and calling `.buffer()` and `.area` redundantly inside an O(N^2) comparison loop introduces a massive performance bottleneck. Also, catching `Exception` instead of specifically `TopologicalError` is necessary for backward compatibility with different Shapely versions handling invalid geometries.
**Action:** Always pre-compute Shapely objects, buffered geometries, and their original areas in O(N) time before entering O(N^2) nested loops like NMS. Inline the required geometry operations directly to bypass expensive function call overhead and duplicate instantiations, using a `try...except Exception` block inside the pre-computation to safely default invalid polygons to `None` for downstream caching logic.
