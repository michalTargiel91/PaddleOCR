## 2025-02-20 - Optimize poly_nms with Shapely precomputation
**Learning:** The `poly_nms` function was bottlenecked by a O(N^2) loop where `points2polygon` and polygon buffering was computed repeatedly for the same polygons inside the loop. Inlining the intersection calculation with `buf_A.intersection(buf_B)` and avoiding repeated computations yields a 18x+ speedup. Note that mathematical anomalies can result in `area_union <= 0` or `shapely.errors.TopologicalError`, requiring a fallback to the original unmodified bounding box logic for those specific iterations.
**Action:** Look for O(N^2) inner loops where object creation (like Shapely polygons) and geometry operations (like `.buffer()`) can be hoisted out and precomputed in an O(N) pass. Be sure to catch `shapely.errors.TopologicalError` in Shapely operations to ensure correctness for complex/degenerate shapes.
