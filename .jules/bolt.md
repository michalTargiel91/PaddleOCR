## 2024-05-18 - Optimize poly_nms by pre-computing polygons
**Learning:** In `ppocr/utils/poly_nms.py`, the Non-Maximum Suppression (NMS) routine recomputes Shapely `Polygon` objects and their buffers multiple times in a nested loop (O(N^2)). Pre-computing these `Polygon` objects, buffering them once, and storing their area reduces the NMS execution time drastically. Furthermore, the pre-computation must be wrapped in `try...except Exception` blocks to handle invalid geometries. Degenerate geometries are set to `None` to skip IOU calculation. Intersecting the pre-computed polygons using Shapely operations must also be wrapped in `try...except` to protect against `TopologicalError`. In order to maintain output parity, we need to un-buffer individual polygon calculations like `poly.area` but intersect using `poly.buffer()`.
**Action:** Always seek to pre-calculate repetitive object instantiation and expensive geometry operations outside loops, especially O(N^2) ones like NMS. Use robust `try...except` fallback for geometry intersections.
